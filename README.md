# Aim Trainer · 练枪训练营（主作品）

类「无畏契约训练营」的瞄准训练器：人偶靶以不同速度与频率刷新在靶场各处，命中计分，60 秒结算。

## 玩法

- 鼠标瞄准，**左键射击**；手枪为单发，其余武器可按住连发
- **R** 换弹（弹匣打空自动换）
- **P / 空格** 暂停，**Esc** 结束本局
- 60 秒内尽量提高得分，连击有加成（最高 +60%）

## 四个角色（选择后获得被动）

| 角色 | 被动 | 适合 |
|---|---|---|
| 疾风 | 射速 +12% | 快速拉枪、压枪节奏 |
| 铁壁 | 后坐力 −35% | 稳点、远距离 |
| 幽灵 | 换弹时间 −40% | 高射速武器持续输出 |
| 鹰眼 | 爆头伤害 +60% | 追求一枪爆头 |

角色立绘是**程序化绘制**的（Canvas 几何图形组合），不是贴图：疾风的护目镜、铁壁的头盔、幽灵的兜帽面罩、鹰眼的贝雷帽与单眼瞄准镜。

## 四把武器

| 武器 | 伤害 | 射速 | 弹匣 | 扩散 | 模式 |
|---|---|---|---|---|---|
| 手枪 | 36 | 4.2 发/秒 | 12 | 0.9 | 单发 |
| 步枪 | 26 | 9.3 发/秒 | 30 | 1.5 | 连发 |
| 冲锋枪 | 17 | 14.3 发/秒 | 25 | 2.4 | 连发 |
| 重机枪 | 23 | 11.3 发/秒 | 60 | 3.2 | 连发 |

## 弹道与命中

- 弹着点 = 准星位置 **+ 随机扩散**（扩散随连射累积、停火收敛）
- 人偶靶分**头 / 身**两个判定区：爆头 2 倍伤害，配合「鹰眼」被动可达 3.2 倍
- 靶子血量 100，击杀 +100 分、爆头击杀 +150 分，再乘连击系数
- 靶子有存活倒计时，超时消失并断开连击

## 难度

| 难度 | 刷新间隔 | 存活时间 | 场上上限 |
|---|---|---|---|
| 简单 | 1.30s | 2.6s | 3 |
| 普通 | 0.95s | 1.9s | 4 |
| 困难 | 0.65s | 1.35s | 6 |

## 结算统计

得分 · 命中率 · 击杀数 · 爆头率 · KPS · 最高连击。

# Vision Catcher · 视觉接球（体感作品）

用摄像头体感玩：把手伸到摄像头前，用身体「罩住」飘动的光球。

- 摄像头画面降采样到 80×60 灰度图做帧差（亮度差阈值 26），取运动质心映射为屏幕坐标并指数平滑，作为玩家输入
- 无摄像头自动降级为鼠标模式
- 粒子系统：背景星点 / 光球环绕 / 命中爆炸 / 玩家拖尾
- 三档难度，P 暂停、Esc 结束

## 本地运行

两个作品都是单文件，但若要开摄像头需 `localhost` 或 `https`：

```bash
python -m http.server 8777
# 打开 http://127.0.0.1:8777/index.html
```

## 技术说明

- 全部视觉元素（角色立绘、人偶靶、枪械、靶场透视网格）均为 Canvas 实时绘制
- 音效由 WebAudio 实时合成（噪声爆发 + 振荡器），不加载任何音频文件
- 无任何 npm 依赖、无构建步骤
