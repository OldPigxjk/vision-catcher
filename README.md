# Vision Catcher · 视觉接球

一个用**摄像头体感**玩的网页小游戏：把手伸到摄像头前，用你的身体去「罩住」屏幕上飘动的光球。60 秒计时，连击越多加成越高。

纯原生 **Canvas + JavaScript**，单文件实现，**零第三方游戏引擎、零外部依赖**，断网也能跑。

> 独立开发（借助 AI 编程工具辅助编码）。作者：徐健凯

---

## 玩法

1. 打开页面，点击「开始游戏」，浏览器会请求摄像头权限（本地文件打开时需用本地服务器，见下文）
2. 画面背景是你的实时摄像头画面（镜像显示）
3. 屏幕上有若干个发光球在飘动
4. **用手或身体去罩住光球** —— 命中即得分，连续命中触发连击加成（最高 5 倍）
5. 60 秒结束结算分数

没有摄像头？点「没有摄像头？用鼠标玩」，用鼠标移动即可。

## 技术实现

### 输入：实时运动检测（不使用任何模型/库）

| 步骤 | 做法 |
|---|---|
| 1. 取样 | `getUserMedia` 获取摄像头画面，逐帧绘制到隐藏的 80×60 小画布 |
| 2. 转灰度 | `0.299R + 0.587G + 0.114B` |
| 3. 帧差 | 与上一帧逐像素比较，亮度差 > **26** 记为「运动像素」 |
| 4. 质心 | 统计运动像素的加权质心，映射回屏幕坐标 |
| 5. 平滑 | 指数平滑（`lerp` 系数按帧间隔自适应），消除抖动 |
| 6. 动态半径 | 以运动包围盒的跨度推算半径，随动作幅度伸缩 |

**为什么要做平滑**：原始质心会随噪声跳变，直接当作输入时手感「飘」且难以精确对位。
实测对比过三种映射方式：

- 质心直连 —— 灵敏但抖，难微调
- 重心加权 —— 稍稳但滞后
- **平滑跟随 + 动态半径 —— 采用**：既跟手又不抖

### 渲染

- 单 `canvas` 全屏绘制，`devicePixelRatio` 适配高分屏
- 光球用径向渐变叠加出光晕
- 右上角环形倒计时，最后 10 秒变红
- 摄像头背景做暗化渐变处理，保证前景可读性

### 容错

- 摄像头不可用 / 权限被拒 → 自动降级为鼠标模式，游戏仍可玩
- 帧间隔上限 50ms，防止切后台回来后瞬移
- `requestAnimationFrame` 驱动，逻辑与渲染同帧

## 本地运行

摄像头 API 需要安全上下文（`localhost` 或 `https`），直接双击 `file://` 打开可能被浏览器拒绝。用任意静态服务器即可：

```bash
# 方式一：Python（Windows / macOS / Linux 通用）
python -m http.server 8777
# 然后浏览器打开 http://127.0.0.1:8777/vision-catcher.html

# 方式二：Node
npx serve .
```
